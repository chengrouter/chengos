## 制作执行清单

1. **素材录制**（优先级从高到低）：
   - [ ] 编辑器画布搭建 + 测试运行（镜 8、15）——核心镜头，建议 60fps 录屏
   - [ ] 发布 → 手机 H5 使用（镜 10）
   - [ ] 会议 Skill 端到端跑通（镜 11）——需提前准备好演示数据
   - [ ] CLI 连接与对话（镜 12，可用截图 06/07 底稿）
   - [ ] RAG 知识库 + 消息渠道（镜 13）
   - [ ] `./chengos.sh` 安装过程（镜 14，可加速播放）
2. **静态素材**：README 中 7 张官方截图（deploy/config/image/01–07.png）作补充/转场底图；架构图（镜 7）需重绘成动效版。
3. **配音**：全片约 380 字旁白，语速 220 字/分钟，建议男声沉稳 + 女声 CTA；BGM 前段低沉、镜 6 起转明快。
4. **合规注意**：
   - 不使用“开源”字样（项目为免费使用但不开源），统一说“免费使用”；
   - 演示账号 `demo@chengrouter.com / demo123456` 可公开显示（README 已公开）；
   - 消息渠道 Logo（钉钉/企微/Telegram 等）注意商标使用规范，可用文字替代。
5. **字幕规范**：关键术语首次出现带英文（MCP、RAG、DAG、Skill），全程中文字幕。
